    November 18 H100 rerun¶

    Dataset: 2026-11-18-h100. All 145 recorded source revisions compiled and executed with exit status zero. The categories below describe evidence scope; an API probe or a host model is not a successful numerical GPU workload.

    Evidence category Programs
    API validation (recorded scope) 13
    API/host demonstration (exit-only) 21
    Host program/model (exit-only) 77
    Numerical/transport validation (recorded scope) 34

    Execution manifest · System records · Integrity inventory. Each program’s chapter contains normalized commands, timestamp scope, source hash and captured output.

    Rows without a per-program timestamp explicitly use their recorded run-batch start UTC. Hardware and tool metadata remain attached to each original run; combining matching sources from reruns does not redate earlier executions.

    This dataset covers the captured hardware and single-node configurations. Host-only models validate their own modeled arithmetic, not real network performance. It does not establish multi-node behavior, failure recovery under physical faults, or benchmark throughput. H100 and A100 evidence are published separately. B200 execution is planned; no B200 results are published. A100 execution does not establish B200 compatibility or results.

    Six host-only models have since been corrected and compiled/executed locally (98, 110 and 111; 96, 113 and 137). Example 17 has a producer-completion correction awaiting GPU revalidation. The records below preserve the earlier source revisions and their actual outputs.

    MPI error-handling diagnostic: failed attempt and successful rerun¶

    The vendor Open MPI 4.1.7rc1 build compiled argument checking out. Example 59 intentionally sends to an invalid rank; that stack crashed inside its UCX send path instead of returning MPI_ERR_RANK. The source was unchanged. An isolated Ubuntu Open MPI 4.1.6 installation with argument checking enabled returned the expected error and exited normally. This is a CPU/MPI error-handler demonstration, not a numerical GPU workload or an RDMA test.

    The final dataset selects 144 successful first-run records plus the successful, separately identified example-59 rerun. The failed attempt remains in the raw first-run records above; it is not counted as a successful execution.
